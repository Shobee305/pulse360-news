PULSE 360

نیوز روم / ایڈیٹر

یہ PULSE 360 کے لیے موبائل فرینڈلی مواد شائع کرنے والے نظام کا ابتدائی حصہ ہے۔

اہم: یہ ایڈیٹر تبھی اصل ویب سائٹ پر خبریں شائع کرے گا جب GitHub repository، Cloudflare Pages اور لاگ اِن کی اجازت درست طور پر جوڑ دی جائے۔ صرف یہ فائل اپ لوڈ کرنے سے خبریں خودکار طور پر پبلش نہیں ہوں گی۔

اگلے مراحل

  1. GitHub پر pulse360-news نام کی repository بنائیں۔
  2. ویب سائٹ کی فائلیں repository میں اپ لوڈ کریں۔
  3. Cloudflare Pages کو repository سے connect کریں۔
  4. admin/config.yml میں repository اور OAuth کی ترتیبات مکمل کریں۔
  5. پھر /admin/ سے نئی خبر، تصویر اور تحریر شامل کی جا سکے گی۔
